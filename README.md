# MyNote
Android Jetpack Compose Project

## Deskripsi

Aplikasi Android untuk mencatat informasi menggunakan Jetpack Compose.
Pengguna dapat membuat, mengubah, menghapus, serta melihat daftar catatan dengan antarmuka yang sederhana dan modern.

## Fitur

- Menampilkan daftar catatan
- Menambah catatan
- Mengubah catatan
- Menghapus catatan
- Material 3 UI
